# Sistema de Biblioteca em Java

Projeto de terminal para praticar relacionamentos entre objetos.

## Conceitos praticados

- classes, objetos e encapsulamento;
- composição;
- listas com `ArrayList`;
- estados de um objeto;
- métodos com retorno booleano;
- regras simples de negócio.

## Como executar

```bash
javac -d out src/*.java
java -cp out Main
```

## Funcionalidades

- cadastrar livros;
- cadastrar usuários;
- emprestar livros;
- devolver livros;
- listar o acervo.
